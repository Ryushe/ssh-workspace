# Windows client handoff

- Intent: provide a native Windows client and let OpenSSH choose an existing identity, including agent-backed identities and per-host configuration.
- Branch/worktree: `feat/windows-client`, `../ssh-workspace-windows`.
- Base: local `main` / `origin/main` at `7a082e5`; target: `main` via review. Fetched origin main over HTTPS at `7a082e5`; it is an ancestor of this branch.
- Contract: Windows installer builds an executable with PyInstaller, installs it per-user, and adds its directory to PATH. Generated PowerShell scripts invoke that executable; `--host` defaults to the workspace name; optional user, port, and key settings are left to OpenSSH when omitted. An optional selected WSL distribution owns host aliases and keys; Windows can invoke its OpenSSH without copying keys. The CLI can generate new keys in WSL and select a same-named key when saving a host. Linux server behavior is unchanged.
- Evidence: Python unittest suite and generated PowerShell invocation on Linux; PowerShell installer parsed and built on Windows; generated native Hoster command resolved and returned its tmux default; native Windows SSH authenticated to Hoster; isolated OpenSSH configuration resolved with ssh -G and Windows-to-WSL execution exercised with an isolated HOME. See final test output for results.
- Blocker: Interactive TUI attachment has not been exercised. Run the Windows CI workflow and an interactive workspace connection on a Windows client before release. Native Windows SSH host config permissions are restricted to the current user and verified with ssh -G. Native Windows SSH does not share WSL configuration; the workspace client invokes WSL SSH. Windows-only key import is not implemented.
- Activation: The feature-branch Windows client is installed per-user at `%LOCALAPPDATA%/ssh-workspace/bin`. A local ssh-hoster.cmd uses it; the corresponding Windows public key was added to Hoster authorized_keys. No remote service was restarted.
- Next: Publish the feature branch and review against main; rerun Windows CI and an interactive smoke test before integration.
